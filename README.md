## Para quem sempre tem uma obra em andamento

O Haku reúne sua biblioteca, o que você quer conhecer e aquela leitura que ficou pela metade. Conecte sua conta do AniList para acompanhar listas, avaliações e progresso — e explore o resto no seu ritmo.

| Sua biblioteca | Na hora de ler ou assistir | Para descobrir e compartilhar |
| :--- | :--- | :--- |
| Listas e progresso com AniList + Kitsu | Leitor por links ou catálogo integrado | DNA Match e recomendações |
| Busca por título, gênero e tags | Leitura vertical ou horizontal | Busca de anime por uma cena |
| Downloads para levar offline | Player com seleção de fontes | Cartões de perfil e obras |
| Fila com pausa e retomada | Tradução local de inglês para português¹ | Tutorial dentro do app |

<sub>¹ Disponível após baixar o modelo de tradução.</sub>

## Comece por aqui

1. **[Abra a página da beta](https://github.com/mancenilheira/haku-releases/releases/tag/v1.0.0-beta.5)** e baixe o arquivo `haku-1.0.0-beta.5-arm64.apk`.
2. Abra o APK no celular. Se o Android pedir, autorize a instalação pelo navegador ou gerenciador de arquivos que você está usando.
3. Entre no Haku e siga o tutorial para conhecer a biblioteca e os caminhos de leitura.

Requer **Android 9+ e ARM64**. Os avisos específicos desta versão estão nas notas do release. A versão para PC fica para depois.

<details>
<summary><strong>Qual arquivo eu baixo?</strong></summary>

O arquivo com final **`.apk`** é o aplicativo. `SHA256SUMS.txt` serve para conferir a integridade do download. Os arquivos “Source code” que o GitHub oferece automaticamente contêm apenas a documentação desta página, não o aplicativo.

</details>

O APK anterior, da beta 2, tem um [relatório público no VirusTotal](https://www.virustotal.com/gui/file/c4bd88dfe23ff7dc256e845af317b7e96b704b203315fcb1e4a68a83eb1d89d3). Na análise de 13/10/2026, nenhum mecanismo o sinalizou como malicioso. Esse relatório corresponde somente à beta 2, não à versão atual. Isso é uma verificação adicional, não uma garantia de segurança; o relatório mostra também os mecanismos que não concluíram a análise ou não suportam o formato.
